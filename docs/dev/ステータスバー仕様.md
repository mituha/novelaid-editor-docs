# ステータスバー仕様

## 1. 概要
ステータスバーは、小説執筆エディタの最下部に常駐し、現在編集中のドキュメントの基本情報（ファイル名、形式）、リアルタイムな文字数・行数などの各種メトリクス、画面レイアウトの切り替え、設定へのアクセスなどの操作インターフェースをユーザーに提供する重要なUIコンポーネントです。

---

## 2. 現行仕様（novelaid-editor）
現行の `novelaid-editor` におけるステータスバーは、以下の構成および機能を持っています。

### 2.1. 画面レイアウト
- **配置**: アプリケーションウィンドウの最下部に全幅（100vw）で配置されます。
- **高さ**: 28px（またはCSSで規定される高さ）。
- **構造**: Flexbox を使用して、左側の操作・ファイル情報グループと、右側の分析・アクションボタンのグループに分かれています。

### 2.2. 左側グループ（操作・基本情報）
1. **ホームボタン (Home)**
   - アイコン: `Home` (Lucide)
   - 機能: クリックすると、エディタ画面から書庫一覧（プロジェクトランチャー等）へ戻ります。
2. **左サイドパネルトグル (PanelLeft)**
   - アイコン: `PanelLeft` (Lucide)
   - 機能: 左サイドバー（ファイルエクスプローラー等）の表示/非表示を切り替えます。
3. **設定ボタン (Settings)**
   - アイコン: `Settings` (Lucide)
   - 機能: エディタ設定ダイアログ（SettingsModal）を開きます。
4. **ファイル情報表示 (File Info)**
   - アイコン: ドキュメントの種類に応じたアイコン（`DocumentIcon`）
   - 表示項目:
     - ファイル名 (例: `第一話.txt`)
     - ドキュメント種別 (例: `Novel` などのメタデータ、または `Markdown`, `Text` などの形式名)

### 2.3. 右側グループ（分析・状態表示）
1. **文字数・行数表示エリア (Metrics Display)**
   - **通常時**: 基本文字数（空白・改行除く）と総行数を表示します。
     - 表示例: `文字数: 3,450 行数: 120`
   - **テキスト選択時**: 選択範囲内の基本文字数を動的に表示します。
     - 表示例: `選択中: 150 / 3,450`
   - **インタラクション**: クリックすることで「文字数詳細分析ポップアップ」を開閉します。
2. **右サイドパネルトグル (PanelRight)**
   - アイコン: `PanelRight` (Lucide)
   - 機能: 右サイドバー（メタデータパネル等）の表示/非表示を切り替えます。
3. **フルスクリーン切り替えボタン (Fullscreen)**
   - アイコン: `Maximize` / `Minimize` (Lucide)
   - 機能: アプリケーションのフルスクリーン表示を切り替えます。
4. **ヘルプボタン (Help)**
   - アイコン: `HelpCircle` (Lucide)
   - 機能: オンラインマニュアルのWebページを外部ブラウザで開きます。

### 2.4. 文字数詳細分析ポップアップ
文字数表示エリアをクリックすると表示されるポップオーバー（吹き出し）UIです。`novelaid-ruby` パッケージの `countCharacters` 関数から返される `DetailedCountResult` を元に、以下の詳細なメトリクスを表示します。

- **基本カウント**:
  - 基本文字数（空白・改行除く）
  - 文字数（空白・改行含む）
  - 総文字数 (RAW長)
  - 総行数
  - 原稿用紙換算枚数 (400字詰め換算。※改行による行消費も考慮して算出)
- **文体分析（セリフと地の文の比率）**:
  - セリフ（カギ括弧 `「` `『` 等で始まる行）と地の文の文字数および行数。
  - セリフ比率 vs 地の文比率を視覚的なカラーバー（グラフ）で表示。
- **空白・改行内訳**:
  - 全角スペースの数
  - 半角スペースの数
  - 改行コードの数

### 2.5. パフォーマンス考慮（Debounce）
長文執筆時の入力パフォーマンス（タイピングの応答性）を維持するため、エディタのテキスト変更イベントから以下の遅延処理を入れて文字数を再計算します。
- **全体文字数カウント**: 200ms のデバウンス (Debounce)
- **選択範囲文字数カウント**: 100ms のデバウンス (Debounce)

## 3. 次世代仕様への検討（novelaid-editor-next）
`novelaid-editor-next`（Tauri 2.0 + React 19 + TypeScript + Vite）への移植にあたり、以下の設計方針で実装を進めます。

### 3.1. レイアウトと統合設計
- **親レイアウトの修正**:
  `src/pages/MainLayout.tsx` のコンテナを縦方向の Flexbox（`flex-direction: column`）にし、上部にエディタ・サイドバー領域（`flex: 1`）、最下部に `StatusBar` を配置します。これにより、ステータスバーが常に画面最下部に固定されます。
- **テーマカラーとの連動**:
  `src/theme.css` で定義されているCSS変数（`--bg-secondary`, `--border-color`, `--text-secondary` 等）を参照し、エディタ全体と調和するモダンな配色にします。

### 3.2. Tauri 2.0 API との連携
- **フルスクリーン制御**:
  `@tauri-apps/api/window` を使用し、ネイティブウィンドウのフルスクリーン状態をトグル制御・同期します。
- **外部ブラウザ起動**:
  `@tauri-apps/plugin-opener` を使用して、オンラインマニュアルのURLを安全に外部ブラウザで起動します。
- **ファイルパスの解決**:
  Windows/macOS等のOS差異を考慮したパス区切り文字の対応と、Tauriのファイルシステムプラグインとの連携を行います。

### 3.3. 機能拡張・改善案
1. **デフォルト表示文字数の切り替え設定**:
   - `SettingsModal`（設定画面）に「ステータスバーのデフォルト文字数表示」オプションを追加します。
   - 選択肢: 「基本文字数（空白・改行除く）」（デフォルト） / 「文字数（空白・改行含む）」
   - ユーザーの執筆スタイル（小説投稿サイトごとの規定など）に合わせて、通常時に表示する文字数を柔軟に切り替えられるようにします。
2. **Web Worker を用いた文字数カウントの完全非同期化**:
   - テキスト全体の文字数カウント処理（`countCharacters`）および正規表現によるルビ除去処理（`stripRuby`）を Web Worker に委譲します。
   - 数万〜数十万文字の長編小説を編集する場合でも、タイピング時のプチフリーズ（メインスレッドのブロック）を完全に排除します。
3. **データ構造の共通化**:
   - `novelaid-ruby` で定義された `DetailedCountResult` インターフェースを `novelaid-editor-next` 側でも共通で利用し、APIの整合性を維持します。
