# 文字数カウント仕様

## 1. 概要
小説執筆エディタにおいて、文字数は執筆の進捗管理や、各小説投稿サイトのシステム制限、あるいは公募コンテストの規定などを満たすための極めて重要な指標です。
本ドキュメントでは、`novelaid-editor` および `novelaid-ruby` でサポートすべき文字数カウントの仕様、各種投稿サイトのカウントルールの違い、およびその具体的な実装案について定義します。

---

## 2. 各種投稿サイト・環境のカウント仕様
主要な小説投稿サイトやメディアプラットフォームにおける文字数のカウントルールは、以下のように仕様が異なります。

| サイト / 規格名 | ルビ文字（ふりがな） | ルビ用記号・タグ（`｜` `《》`） | 改行 | 空白（全角・半角スペース） | 備考 |
| :--- | :--- | :--- | :--- | :--- | :--- |
| **カクヨム** | **除外** | **除外** | **除外** | **除外** | 純粋な本文の日本語文字のみカウントされる |
| **小説家になろう** <br>(空白・改行含まず) | **除外** | **除外** | **除外** | **除外** | 小説情報やランキング等に表示される標準の文字数 |
| **小説家になろう** <br>(空白・改行含む) | カウント | カウント | カウント | カウント | 1話あたり最大7万文字のシステム制限（保存上限）用 |
| **ノベルアッププラス** | **除外** | **除外** | **除外** | **除外** | カクヨムとほぼ同様のクリーンなカウント |
| **アルファポリス** | カウント | カウント | **除外** | **除外** | ルビや記号も文字数として積算される |
| **note / Tales** | カウント | カウント | **除外** | **除外** | ルビ文字や装飾用記号もカウントに含まれる |
| **原稿用紙換算 (400字詰め)** | - (カウントしない) | - (カウントしない) | 含む | 含む | 行あたり20文字で改行により行を消費する換算方法 |

---

## 3. 機能要件

### 3.1. 複数文字数カウントの同時算出
ユーザーが設定でプリセットを切り替える手間を省くため、本エディタではプリセットの概念を廃止し、以下の2つの文字数を同時に算出・保持します。
- **基本文字数（空白・改行なし）**: ルビ、ルビ用記号、空白（全角・半角スペース）、改行を除外した文字数（カクヨム、小説家になろう等の標準カウントに相当）。
- **文字数（空白・改行あり）**: ルビ、ルビ用記号を除外し、空白や改行はそのままカウントに含めた文字数（小説家になろうのシステム制限文字数等に相当）。

原稿用紙換算については、別途「原稿用紙換算枚数」として算出します。

### 3.2. セリフと地の文の分離カウント
小説の文体を分析するため、セリフと地の文を区別したカウント機能を提供します。
- **セリフ（Dialogue）**: カギ括弧（`「...」` や `『...』` など）で始まる行、またはその内部の文字列。
- **地の文（Narrative）**: セリフ以外の部分。
- それぞれの基本文字数（空白・改行なし）、文字数（空白・改行あり）、行数、および全体に対する比率（%）を算出します。

### 3.3. 選択範囲のカウント
エディタ上でテキストが選択されている場合、ステータスバーなどの表示を選択範囲の文字数（例: `選択中: 120 / 全体: 3,500`）に動的に切り替えます。

### 3.4. パフォーマンス考慮（Web Worker / Debounce）
数万文字を超える長文の執筆中、キー入力（リアルタイム）で正規表現によるルビの除去や複雑なカウント処理を同期的に実行すると、UIのレンダリングやタイピングのレスポンスが低下（プチフリーズ）する原因となります。
- **対策案**:
  1. カウント処理を非同期化し、入力から一定時間（例: 200ms）遅延して実行する（Debounce）。
  2. 重い解析（セリフ分析やルビ抽出など）は Web Worker に委譲し、メインスレッドの負荷を軽減する。

## 4. 実装案 (`novelaid-ruby` への統合)
文字数カウントのコアロジックは、エディタに依存しない汎用的な機能であるため、`novelaid-ruby` パッケージ内で定義します。

### 4.1. データ構造の設計
以下のような型定義を `novelaid-ruby` の `src/core/counter.ts` に実装します。

```typescript
export interface DetailedCountResult {
  // 基本メトリクス
  rawLength: number;               // 単純な text.length
  charCount: number;               // ルビ・記号・空白類を除外した文字数（カクヨム準拠、基本）
  charCountWithSpaces: number;     // ルビ・記号を除外し、空白類を含めた文字数
  lineCount: number;               // 総行数

  // 空白・改行の内訳
  spaces: {
    halfWidth: number;             // 半角スペース数
    fullWidth: number;             // 全角スペース数
    total: number;
  };
  newlines: number;                // 改行コードの数

  // セリフと地の文
  dialogue: {
    charCount: number;             // セリフの文字数（空白・改行除外、基本）
    charCountWithSpaces: number;   // セリフの文字数（空白・改行含む）
    lineCount: number;             // セリフの行数
  };
  narrative: {
    charCount: number;             // 地の文の文字数（空白・改行除外、基本）
    charCountWithSpaces: number;   // 地の文の文字数（空白・改行含む）
    lineCount: number;             // 地の文の行数
  };

  // 原稿用紙換算 (400字詰め等)
  manuscriptSheets: number;        // 換算枚数 (小数)
}

export interface CountOptions {
  manuscriptCharsPerLine?: number;  // 原稿用紙の1行あたりの文字数 (デフォルト: 20)
  manuscriptLinesPerSheet?: number; // 原稿用紙の1枚あたりの行数 (デフォルト: 20)
}
```

### 4.2. カウントアルゴリズム案
```typescript
import { stripRuby } from './formatter';

/**
 * 詳細な文字数カウントメトリクスを算出します。
 * ルビや記号は常に除外してカウントします。
 * @param text 執筆された原稿のテキスト
 * @param options カウントオプション (原稿用紙換算設定など)
 */
export function countCharacters(text: string, options: CountOptions = {}): DetailedCountResult {
  const charsPerLine = options.manuscriptCharsPerLine || 20;
  const linesPerSheet = options.manuscriptLinesPerSheet || 20;

  // 1. 基本的なカウント
  const rawLength = text.length;
  const halfWidthSpaces = (text.match(/ /g) || []).length;
  const fullWidthSpaces = (text.match(/\u3000/g) || []).length;
  const newlines = (text.match(/\n/g) || []).length;

  // ルビとルビ記号を常に除外した基本テキストを作成
  const textWithoutRuby = stripRuby(text);

  // 2. セリフと地の文の抽出・カウント
  let dialogueChars = 0;
  let dialogueCharsWithSpaces = 0;
  let dialogueLines = 0;
  let narrativeChars = 0;
  let narrativeCharsWithSpaces = 0;
  let narrativeLines = 0;

  // 原文の行でループを回し、セリフか地の文かを判定
  const originalLines = text.split('\n');
  
  // ルビなしテキストの各行を取得（原文と1対1で対応）
  const rubyStrippedLines = textWithoutRuby.split('\n');

  originalLines.forEach((line, index) => {
    // 簡易的なセリフ判定: 原文の行頭がカギ括弧系（「 または 『）であるか
    const isDialogueLine = /^\s*[「『]/.test(line);
    
    const strippedLine = rubyStrippedLines[index] || '';
    
    // 空白類を完全に除外した文字列
    const cleanLine = strippedLine.replace(/[\s\u3000]/g, '');
    
    // 空白類を含む文字数（行末の改行は含めず、その行の中の文字数）
    const lineCharsWithSpaces = strippedLine.length;

    if (isDialogueLine) {
      dialogueChars += cleanLine.length;
      dialogueCharsWithSpaces += lineCharsWithSpaces;
      dialogueLines++;
    } else {
      narrativeChars += cleanLine.length;
      narrativeCharsWithSpaces += lineCharsWithSpaces;
      narrativeLines++;
    }
  });

  // 改行コード自体の数をセリフ/地の文の「空白・改行含む」カウントに分配
  originalLines.forEach((line, index) => {
    if (index < originalLines.length - 1) {
      const isDialogueLine = /^\s*[「『]/.test(line);
      if (isDialogueLine) {
        dialogueCharsWithSpaces += 1; // 改行コード分
      } else {
        narrativeCharsWithSpaces += 1; // 改行コード分
      }
    }
  });

  // 3. 全体文字数の計算
  // 基本文字数（ルビ除外、空白・改行除外）
  const charCount = textWithoutRuby.replace(/[\s\u3000]/g, '').length;
  // 空白・改行含む文字数（ルビ除外、空白・改行含む）
  const charCountWithSpaces = textWithoutRuby.length;

  // 4. 原稿用紙換算（全角・半角スペースや改行による行消費を考慮）
  let totalLinesConsumed = 0;
  rubyStrippedLines.forEach(line => {
    const lineLen = line.length;
    // 改行により最低でも1行消費
    totalLinesConsumed += lineLen === 0 ? 1 : Math.ceil(lineLen / charsPerLine);
  });
  const manuscriptSheets = totalLinesConsumed / linesPerSheet;

  return {
    rawLength,
    charCount,
    charCountWithSpaces,
    lineCount: originalLines.length,
    spaces: {
      halfWidth: halfWidthSpaces,
      fullWidth: fullWidthSpaces,
      total: halfWidthSpaces + fullWidthSpaces,
    },
    newlines,
    dialogue: {
      charCount: dialogueChars,
      charCountWithSpaces: dialogueCharsWithSpaces,
      lineCount: dialogueLines,
    },
    narrative: {
      charCount: narrativeChars,
      charCountWithSpaces: narrativeCharsWithSpaces,
      lineCount: narrativeLines,
    },
    manuscriptSheets,
  };
}
```

## 5. UIへの統合案
`novelaid-editor` 側のUI（ステータスバーや設定、詳細表示）への組み込み手順。

### 5.1. 設定画面への追加
- 「エディタ設定」タブ等に「ステータスバーのデフォルト文字数表示」の設定項目を追加します。
  - 選択肢: 「基本文字数（空白・改行を除く）」（デフォルト） / 「文字数（空白・改行を含む）」
  - 選択された設定値を `editorConfig` に保存します（例: `editorConfig.defaultCharCountType`）。

### 5.2. ステータスバーへの反映
- ステータスバーには、設定されたデフォルトタイプに基づく文字数（例: `文字数: 3,200` または `文字数(空白込): 3,500`）を表示します。
- 選択範囲が存在する場合、一時的に `選択中: 150 / 3,200` のように表示を切り替えます。
- ステータスバーの文字数表示部分をクリックした際に、ポップオーバーまたはツールチップで詳細なメトリクスを表示する「文字数詳細ポップアップ」を提供します。

### 5.3. 文字数詳細ポップアップ（ポップオーバー）
ステータスバーから開くことができるポップアップで、以下の情報を表やグラフ（インジケーター）でビジュアルに表示します。
- **基本文字数（空白・改行なし）**: カクヨム、小説家になろうの標準カウント相当。
- **文字数（空白・改行あり）**: 小説家になろうのシステム上限（7万字制限）相当。
- **総文字数（RAW）**: ルビ記号等を含む完全なテキスト長（`text.length`）。
- **原稿用紙換算枚数（400字詰め換算）**
- **セリフ割合**: セリフ文字数 vs 地の文文字数のパーセンテージと行数の比較。
- **空白・改行の内訳**: 全角スペース、半角スペース、改行のそれぞれのカウント。
