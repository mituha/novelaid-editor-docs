# 設定プラグイン分離仕様書（restar-app-settings / tauri-plugin-restar-settings）

## 1. 概要

本ドキュメントは、**`novelaide`** において実装された設定システム（`SettingsRegistry`, `SettingsModal`, `SettingsContext`）を、他のTauriアプリケーション（`restar-app` エコシステム等）でも横断的に再利用可能にするため、独立した **Tauriプラグイン（`tauri-plugin-restar-settings` / `restar-app-settings`）** として構造的に分離・パッケージ化する仕様を定義するものです。

---

## 2. プラグインの命名と責務

| 対象 | 名称 | 責務・役割 |
| :--- | :--- | :--- |
| **Rust クレート** | `tauri-plugin-restar-settings` | OS標準のアプリ設定ディレクトリ（`AppConfig`）における `settings.json` の安全な読み書き・永続化・パス解決 |
| **npm パッケージ** | `restar-app-settings` | React向けの共通UIコンポーネント（`SettingsModal`）、レジストリ（`SettingsRegistry`）、状態管理コンテキスト（`SettingsContext`, `useSettings`）の提供 |

---

## 4. Tauri コマンド仕様

### `load_settings`
- **引数**: なし
- **戻り値**: `serde_json::Value`
- **動作**: OS標準の `AppConfig` ディレクトリ内の `settings.json` を読み込む。ファイルが存在しない場合は空オブジェクト `{}` を返す。

### `save_settings`
- **引数**: `settings: serde_json::Value`
- **戻り値**: `Result<(), String>`
- **動作**: 親ディレクトリが存在しない場合は自動生成し、`settings.json` をアトミックに書き込む。

### `get_settings_path`
- **引数**: なし
- **戻り値**: `String`
- **動作**: 現在のアプリケーションの設定ファイルフルパスを返す。

## 5. アプリケーション（ホスト側）での利用フロー

各アプリは、独自の設定項目を「設定タブプラグイン」として定義し、プラグインの `SettingsModal` をマウントするだけで設定画面が機能します。

```tsx
import { SettingsProvider, SettingsModal, settingsRegistry, type SettingTabPlugin } from 'restar-app-settings';

// 独自タブの登録
settingsRegistry.register({
  id: 'my-feature',
  title: '独自機能設定',
  order: 10,
  defaultValues: { enabled: true },
  render: ({ settings, updateSetting }) => (
    <div>...</div>
  )
});

// アプリケーションへの組み込み
function App() {
  return (
    <SettingsProvider>
      <MainView />
      <SettingsModal />
    </SettingsProvider>
  );
}
```
