# ルビ関連仕様

## 概要
小説執筆において不可欠なルビ（ふりがな）および傍点の記法、およびその処理に関する仕様をまとめます。
これらの機能は `novelaid-ruby` ライブラリとして共通化し、エディタ（`novelaid-editor`）やビューア（`novelaid-markdown`）から利用可能にします。

## 対応記法

### 1. ルビ (Ruby)
主に「カクヨム記法」および「なろう記法」に準拠した記法をサポートします。

| 種類 | 記法例 | 備考 |
| :--- | :--- | :--- |
| パイプあり | `｜親文字《ルビ》` | `｜` は半角 `|` も許容します。 |
| パイプなし | `漢字《ルビ》` | 漢字（々、〇を含む）の連続に続く場合に自動適用されます。 |

*   **HTML変換例**: `<ruby>親文字<rt>ルビ</rt></ruby>`
*   **ネスト**: 基本的にルビのネストはサポートしません（内側の記法はテキストとして扱われます）。

### 2. 傍点・圏点 (Bouten)
文字の上に打つ強調用の点をサポートします。

| 種類 | 記法例 | 備考 |
| :--- | :--- | :--- |
| 二重山括弧 | `《《強調》》` | 内部のテキストすべてに傍点を振ります。 |

*   **HTML変換例**: `<span class="bouten">強調</span>`
    *   CSSで `text-emphasis` プロパティを使用してレンダリングします。

## novelaid-ruby ライブラリの役割

`novelaid-ruby` は以下の機能を提供することを目的とします。

1.  **パース (Parse)**: テキスト内のルビ記法を検出し、構造化データ（AST）に変換する。
2.  **変換 (Transform)**: ASTからHTML、プレーンテキスト、各種投稿サイト用形式へ変換する。
3.  **エディタ支援**:
    *   特定のオフセットにおけるルビの有無の判定。
    *   ルビ挿入用のダイアログUI（Reactコンポーネント）の提供。
4.  **バリデーション**:
    *   ルビの長さチェック。
    *   親文字とルビの対応関係の妥当性確認。

## 今後の検討事項
*   **自動ルビ振り**: AIまたは辞書を用いた、選択範囲への自動ルビ適用。
*   **多言語対応**: 中国語（ピンイン）や英語等のルビ（インターリニア）への拡張性。
*   **青空文庫記法への完全対応**: 注釈等を含む複雑な記法のサポート。
