# メタデータ仕様

このドキュメントでは、Novelaid Editor におけるドキュメントのメタデータ（属性情報）の管理・保存、および編集仕様について記載します。

---

## 1. メタデータ基本仕様

### 1.1 保存形式 (YAML Frontmatter)
メタデータは、対象ドキュメント（主に `.txt` および `.md` ファイル）の先頭部分に、**YAML形式のFrontmatter**として保存されます。
メタデータ記述部は `---`（トリプルハイフン）の行で囲まれます。

**例：**
```markdown
---
title: 「初まりの章」
author: 織田信長
description: 物語の導入部分です。
tags:
  - ファンタジー
  - 序章
---
ここから本文が始まります。
```

### 1.2 バックエンド処理 (Rust)
メタデータの抽出および統合処理は、Tauriプラグインの `tauri-plugin-novelaid-fs` が担当しています。
- **読み込み時 (`read_document`):**
  ファイル先頭の `---` で囲まれたYAML部をパースし、JSONオブジェクト (`serde_json::Value`) としてメモリに展開します。本文とメタデータは分離してフロントエンドへ返却されます。
- **書き込み時 (`write_document`):**
  渡されたメタデータオブジェクトを `serde_yaml` でシリアライズし、本文の前に `---` で囲んで結合した上でファイルへ書き込みます。

### 1.3 メタデータキャッシュ機構
- プロジェクト読み込み時、またはファイルをスキャンする際、バックグラウンドのメタデータスキャンワーカーが起動し、ファイル更新時間 (`mtime`) を基に差分検知を行いながら自動的にメタデータをパースしてメモリにキャッシュします。
- キャッシュは `fs:metadata-scan-progress` および `fs:metadata-updated` イベントを介してフロントエンドへリアルタイムに同期されます。

## 2. メタデータエディター仕様

メタデータはフロントエンドの各パネルコンポーネントを介して編集や確認が行えます。

### 2.1 MetadataPanel (Next.js版の基本エディタ)
`novelaid-editor-next` では、`src/components/MetadataPanel.tsx` を用いて以下のフィールドを編集します。
- **共通フィールド (Common Fields):**
  - **タイトル (`title`):** 1行テキスト入力。
  - **著者 (`author`):** 1行テキスト入力。
  - **概要 (`description`):** 複数行テキストエリア。
  - **タグ (`tags`):** 配列形式。UI上はカンマ区切りで入力され、配列に変換されて保存されます。
- **カスタムフィールド (Custom Fields):**
  - 共通フィールド以外の任意のキー値を「フィールドを追加」ボタンから追加・削除可能です。

### 2.2 MetadataPropertyEditor (Electron版の詳細プロパティエディタ)
`novelaid-editor`（Electron版）の `MetadataPropertyEditor.tsx` では、より高度な設定項目を編集できます。

- **基本フィールド:**
  - **タイトル (`title`)**
  - **タグ (カンマ区切り) (`tags`)**: カンマ区切りの文字列入力から配列へ相互変換します。
  - **あらすじ / メモ (`summary` または `description`)**: 複数行テキストエリア。
- **クイックタグトグル (Quick Tags):**
  ワンクリックで指定の役割を示すタグをトグル切り替えできるショートカットボタン群です。
  - **登場人物 (character):** `character`, `登場人物`, `人名`, `人物`, `chara` 等のいずれかが含まれていればアクティブ化。トグルONで `character` が付与されます。
  - **地名・施設 (location):** `location`, `places`, `地名`, `施設`, `場所`, `place`, `geo` 等に対応。
  - **プロット (plot):** `plot`, `構成`, `案`, `timeline`, `時間軸` 等に対応。
- **詳細設定 / キャラクター設定:**
  - **ID (識別子) (`id`):** 一意のID文字列。
  - **表示名 (名前) (`name`):** キャラクター名などに用いる表示名。
  - **アイコン (`icon`):**
    - `value`（Lucideアイコン名、画像URL、またはローカル絶対パス/相対パス）を入力します。
    - 入力値から `type`（`lucide` / `url` / `local`）を自動推論します。
    - ローカルパス画像は `nvfs://local/` カスタムプロトコルスキームを経由してプレビュー表示されます。
- **AIチャット設定 (`chat`):**
  - **ペルソナ有効化 (`chat.enabled`):** チェックボックスによるON/OFF。
  - **口調・追加設定 (Persona) (`chat.persona`):** AIチャットでペルソナとして動作させるための語尾や設定（プロンプト指示）を記述します。

## 3. メタデータビュー・検索一覧仕様

### 3.1 MetadataListPanel (メタデータリストパネル)
`novelaid-editor`（Electron版）の `MetadataListPanel.tsx` は、プロジェクト内から特定のメタデータタグを持つファイルを走査・収集し、サイドバーなどで一覧表示（ブックマーク表示）するためのコンポーネントです。

- **表示モード:**
  1. **固定タグリスト (Fixed Mode):**
     あらかじめ設定されたタグ（例: `character`, `location`, `plot`）に合致するファイルを全自動で一覧表示します。
     - **キャラクター一覧:** `character` 関連タグを持つファイルを抽出。
     - **地名・施設一覧:** `location` 関連タグを持つファイルを抽出。
     - **プロット一覧:** `plot` 関連タグを持つファイルを抽出。
  2. **カスタムリスト (Editable Mode):**
     ユーザーが任意の「タイトル」と「抽出用タグ（カンマ区切り）」を設定して、独自のブックマーク枠を作成・編集できます。このカスタム定義はプロジェクト設定 (`projectConfig.metadataLists`) にシリアライズ保存されます。
- **主なインタラクション:**
  - **ファイル遷移:** 一覧の項目をクリックすると、対象ファイルが自動的にエディターで開きます。
  - **ドラッグ＆ドロップ:** 項目をドラッグして、パス情報を他のコンポーネント（エディタなど）へコピー・配置できます。
  - **自動更新・追従:** ファイルシステムの更新監視イベント (`onFileChange`) や、バックグラウンドのメタデータスキャン進捗 (`isScanning`, `scanProgress`) が完了したタイミングで、リスト内容が自動的に再フェッチされます。

## 4. アプリケーション個別仕様

### 4.1 人工言語 (Conlang) 機能におけるメタデータ
`novelaid-conlang` パッケージにおいて、メタデータは単なる属性情報以上の構造化データ保存用として応用されています。
- `type`: `'conlang'` または `'conlang-meta'`
- その他、音韻論 (`phonology`)、形態論 (`morphology`)、統語論 (`syntax`)、文字体系 (`writingSystem`)、語彙 (`vocabulary`)、例文 (`exampleSentences`) などのオブジェクトがメタデータ領域にネストされて保持されます。
