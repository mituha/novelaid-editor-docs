# インデックス自動生成共通仕様（`index.md` 生成規約）

## 1. 概要と背景

小説プロジェクトの大規模化に伴い、章・エピソード、登場人物シート、世界観設定などが複数のフォルダに階層化されていきます。
これらのフォルダごとに目次やカタログの役割を果たす `index.md` を手動でメンテナンスすることは作家にとって大きな負担となるため、各ファイルの YAML Frontmatter メタデータをもとに `index.md` を自動生成・同期する共通仕様を定義します。

> [!NOTE]
> **OKF（Open Knowledge Format）との親和性について**:
> 本仕様は、ファイル自身が自己記述的なメタデータを持ち、フォルダ単位の index で構造化される OKF のコンセプトと親和性を持っています。ただし現段階では厳格な OKF 規約に拘束されるものではなく、小説執筆の利便性とシンプルな Markdown 構造を最優先としています。

---

## 2. 自動生成におけるコアメタデータ

自動生成エンジンは、同一フォルダ（または指定階層）に存在する各ファイルの YAML Frontmatter から以下の3つのコア項目を抽出します。

| フィールド名 | 型 | 用途 | フォールバック・省略規約 |
| :--- | :--- | :--- | :--- |
| **`title`** | `string` | 見出し名、リンク文字列 | 未指定時はファイル名（拡張子除く）を使用。 |
| **`type`** | `string` | 分類種別、グルーピング、フィルタリング | 未指定時は一般ドキュメントとして扱う。 |
| **`description`** | `string` | 1行の概要・要約文 | 未指定時は空欄（補足文なし）とする。1行テキスト入力を前提とする。 |

---

## 3. 生成レイアウト形式

生成対象フォルダの性質や設定に応じて、以下のレイアウト形式を標準サポートします。

### 3.1 リスト形式（シンプルな目次・エピソード一覧）
各ファイルを1つの箇条書きリスト項目として表現する形式。小説本編の章フォルダやシンプルなメモ一覧に適しています。

```markdown
# 第一章 目覚めと旅立ち

- [第1話 目覚めの森](./ep01.md) - 名もなき森で記憶を失った青年が目を覚ます。
- [第2話 出会いと剣](./ep02.md) - 王女セラフィーナの一行と遭遇し、魔獣の襲来を退ける。
- [第3話 王都への道](./ep03.md) - 保護される形で王都へ向けた護衛旅が始まる。
```

### 3.2 テーブル形式（カタログ・設定資料一覧）
メタデータを列（カラム）に割り当てて表形式で表現する形式。登場人物一覧や世界観用語集など、属性を比較・俯瞰したいフォルダに適しています。

```markdown
# 登場人物設定資料

| 名前・タイトル | 種別 | 概要 |
| :--- | :--- | :--- |
| [神代 玲央](./chara_reo.md) | character | 本作の主人公。記憶を失った元錬金術師。 |
| [セラフィーナ](./chara_sera.md) | character | 神聖王国の第二王女。玲央を保護する。 |
| [バルガス](./chara_vargas.md) | character | 王立騎士団長。玲央の能力を警戒している。 |
```

## 4. `type` による抽出・フィルタリング規約

自動生成時、特定の `type` を持つドキュメントのみをフィルタリングして出力したり、`type` ごとにセクション（見出し）を分割して出力することが可能です。

**例（セクション分割生成）:**
```markdown
# 設定資料インデックス

## 登場人物 (type: character)
- [神代 玲央](./chara_reo.md) - 本作の主人公。
- [セラフィーナ](./chara_sera.md) - 神聖王国の第二王女。

## 舞台・世界観 (type: location)
- [神聖王国ルシエラ](./loc_luciera.md) - 大陸中央部に位置する大国。
```
