# ペルソナ仕様

## 概要

AI関連の応答処理において、エージェントとして仮装の人格を持ったキャラクターとして応答する機能(クラス/エージェント)を「ペルソナ」とします。  
基本的にAIを使用する部分はこの「ペルソナ」を使用する構造として問題ありません。

名称として、アバター、キャラクターも検討はしましたが、今回はペルソナとしました。

## 使用例

* AIチャット
    + 会話形式のチャット機能
    + ユーザーからのプロンプトに対して、ペルソナとして応答を生成します。
    + 特に人格未設定のままの「ペルソナ」
    + 編集者などの特定の組み込み用人格を持つ「ペルソナ」
    + メタデータでキャラクターとマークされた設定を持つ「ペルソナ」
* AI校正
    + 誤字脱字のチェックや推敲、校正などを行います。
    + 編集者などの特定の組み込み用人格を持つ「ペルソナ」

## データ構造

### AiPersona インターフェース

ペルソナの基本データを定義します。

```typescript
export interface AiPersona {
    /** 一意識別子 */
    id: string;
    /** 名称 */
    name: string;
    /** 説明 */
    description: string;
    /** アイコン（Lucideアイコン名） */
    icon?: string;
    /** システムプロンプト */
    systemPrompt: string;
}
```

### BasePersona クラス

`AiPersona` を実装する基底クラスです。将来的にコンテキストに応じた動的なプロンプト生成などの拡張ポイントとして機能します。

## 実装の詳細

### 組み込みペルソナ

以下の3つの人格が標準で用意されています。

1.  **標準アシスタント** (`default`)
    *   汎用的なAIアシスタント。執筆全般をサポート。
2.  **編集者** (`editor`)
    *   プロット相談、物語の構成案、キャラクター設定の深掘りなどに特化。
3.  **校正者** (`proofreader`)
    *   誤字脱字チェック、日本語表現の推敲、事実確認に特化。

### 管理と利用

*   **AiContext**: `builtinPersonas` のリストを管理し、現在選択されている `activePersonaId` を保持します。設定は `settings.json` に保存され、再起動後も維持されます。
*   **ChatContext**: メッセージ送信時に `activePersona.systemPrompt` を AI ドライバーの `system` オプションとして渡し、人格に応じた応答を実現します。
*   **PersonaSelector**: チャットパネル上部のツールバーに配置され、視覚的にアイコンと説明を確認しながら切り替え可能です。

## 今後の展望

*   **ライブラリ化**: 現在は `novelaid-editor-next` 内で実験的に実装されていますが、安定動作確認後に `restar-ai-ts` へ移行し、汎用的な基盤として提供します。
*   **キャラクター連動**: プロジェクト内のキャラクター設定ファイル（メタデータを含む）から自動的に `AiPersona` を生成し、作中キャラクターと会話できる機能の追加を検討します。
*   **カスタムペルソナ**: ユーザーが独自のシステムプロンプトを設定して保存できる機能。
