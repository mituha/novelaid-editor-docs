## D&D

tauriでD&Dが動作しない

```json
  "app": {
    "windows": [
      {
        "title": "novelaid-editor-next",
        "width": 800,
        "height": 600,
        "dragDropEnabled": false
      }
    ],
```
tauri.conf.jsonに`"dragDropEnabled": false`を追加する必要がある。
外部からのD&Dが有効な状態だと内部でのD&Dが動作しない模様。
