# 機能一覧および各アプリ対応状況

## 1. 概要

本ドキュメントは、小説執筆支援システム群として並行開発されている以下の3つのアプリケーションについて、その機能一覧および現在の対応状況をまとめたものです。

* **`novelaid-editor`（現行Electron版）**:
  - 小説執筆に必要な基本機能を網羅した現行の本番稼働エディター。全機能要件の**「基準（リファレンス）」**となります。
* **`novelaide`（先行開発・Tauri 2.x版・コードネーム `novelaid-e`）**:
  - `novelaid-editor` をベースに Tauri 2.x + Rust で完全再設計した次世代IDE。
  - プラグインアーキテクチャ、Rustネイティブ高速処理、バックエンド主導型コマンド実行と自律イベント更新などを先行導入しています。
* **`novelaid-cli`（AIエージェント特化CLI/TUI）**:
  - ターミナル上で作家とAIが対話しながらプロット・設定・本文を執筆・推敲するためのCLIツール。
  - `pi-coding-agent` SDK上に構築され、ローカルLLM自動連携や境界保護付き階層移動（`/cd`, `/ls`）を備えています。

> [!NOTE]
> 過去のプロトタイプ実装である `novelaid-editor-next` の機能・知見はすべて `novelaide` に統合・昇華されています。

## 3. 各アプリの詳細対応状況

### 3.1 `novelaid-editor`（基準・現行Electron版）
小説執筆に必要な全機能を網羅しており、動作仕様の基準となります。
* **強み**:
  * 文章校正（Calibration: textlint等による助詞連続使用・表記揺れチェック）が完全に動作。
  * AIチャット機能（ペルソナ切り替え、執筆相談、壁打ち）が利用可能。
  * 架空言語支援（conlang）による造語生成・辞書機能。
  * 小説投稿サイト（なろう・カクヨム等）向けの一括エクスポート機能（Submission）。
* **課題**:
  * モノリス構造であり機能間の結合が強い。
  * Electronベースのため起動時間・メモリ消費量が大きい。

### 3.2 `novelaide`（先行開発・Tauri 2.x版）
現行版の優れた執筆体験を継承しつつ、アーキテクチャの完全刷新を行った次世代エディターです。
* **強み（先行・進化点）**:
  * **完全プラグインアーキテクチャ**: ビュー（ViewRegistry）、サイドパネル（PanelRegistry）、設定（SettingsRegistry）、エクスプローラー（ExplorerRegistry）が疎結合に設計されており、拡張性が高い。
  * **独立クレート化**: `tauri-plugin-novelaid-fs`、`tauri-plugin-restar-settings`、`tauri-plugin-restar-git` などが独立パッケージ化。
  * **進化したファイル操作基盤**:
    * ファイル名自動推測エンジン（連番・話数・全角数字インクリメント）によるワンクリック即時作成。
    * インライン作成・インラインリネーム（F2キー、拡張子除外選択）。
    * ドラッグ＆ドロップ移動・コピー（Ctrlキー併用、循環移動ガード）。
    * バックエンド主導型コマンド実行（Rust側ネイティブ確認ダイアログ、`fs:changed` イベント発行によるフロントエンド自律更新）。
  * **本格的な Git ソース管理**: Monaco Diff Editor による左右/インライン文字差分比較、SVGコミット履歴グラフ。
  * **超高速ローカル文章校正・ルビ支援**: `Lindera` (v6.x) 内蔵によるミリ秒単位の形態素解析、小説作法チェック、ルビ自動推測、エディター波線ハイライト・ジャンプ。
* **未対応の領域**:
  * 外部ファイル監視（Watcher / `notify` クレート連動）。
  * AIチャット・ペルソナ機能（`novelaid-cli` / `pi-coding-agent` との統合待ち）。
  * 架空言語支援（conlang）。
  * 小説投稿サイト出力（Submission）。

### 3.3 `novelaid-cli`（AIエージェント特化CLI/TUI版）
ターミナル上で作家とAIが共同執筆を行うためのCLIツールです。
* **強み**:
  * `@earendil-works/pi-coding-agent` SDK 上に構築されたリッチな TUI（ストリーミング、Markdown描画、コマンドパレット）。
  * ローカルLLM（LM Studio）の自動検知・接続による完全プライベートな執筆支援。
  * 境界保護付きフォルダー移動（`/cd`, `/pwd`, `/ls`、ルート上限ガード、動的Tab補完）。
* **今後の連携**:
  * `novelaid-cli` で先行構築・検証されたプロンプト体系やツール仕様（Layer 1/2）を、`novelaide`（GUI）へ共通エージェント基盤として提供。
