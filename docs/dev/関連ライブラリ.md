# 関連ライブラリ

関連する機能をライブラリ化して共通化、および、再利用可能な形としていきます。

* https://www.npmjs.com/~mituha
    + novelaid-markdown
    + reatar-app
    + rastar-ai

現状、UI部分の共通化などを含めて、React想定です。

## novelaid-markdown

https://www.npmjs.com/package/novelaid-markdown

小説の設定などをマークダウンで記述する前提でのマークダウンプレビュー表示。
`mermaid.js`形式のコードブロックによる表示などに対応します。

これにより、テキストによる記述での図の表示などを行います。
地図表示も可能。

## restar-app

他のプロジェクトにも流用可能な機能をまとめたもの。

* ProjectLauncher
    + フォルダー単位で扱うプロジェクトでのフォルダー選択用UI
    + 起動時のプロジェクト選択部分を扱います

## restar-ai

AI関連の機能をまとめます。
GeminiとLMStudio用のOpenAI互換APIに対応します。

設定用のUIも提供します。
